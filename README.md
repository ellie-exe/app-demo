# Business Data Dashboard

A simple interactive business data dashboard built with Python and Streamlit to demonstrate data visualization and user-driven filtering.

## Features

- Generates sample monthly sales data
- Visualizes sales trends using an interactive line chart
- Allows users to adjust a sales threshold using a slider
- Dynamically filters and displays months with sales above the selected threshold

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib

## How It Works

1. Monthly sample sales data is generated using Pandas and NumPy
2. Streamlit displays the data as a line chart
3. Users select a sales threshold using an interactive slider
4. The dashboard filters and displays the corresponding sales data
